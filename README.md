#AI PDF Assistant

An AI-powered PDF learning assistant built using Python and Streamlit. It helps users understand PDF documents through AI-generated summaries, quizzes, and question answering.

Features

- PDF Upload and Text Extraction
- AI-Powered PDF Summarization
- Automatic Quiz Generation
- Ask Questions About PDF Content
- Download Summaries and Quizzes
- User Login and Registration

Technologies Used

- Python
- Streamlit
- SQLite
- PyPDF
- Ollama
- Large Language Models (LLMs)

Project Structure

- "app.py" — Main application
- "requirements.txt" — Required Python packages

Run Locally

1. Install Python.

2. Install the required packages:
   
   "pip install -r requirements.txt"

3. Install Ollama and download the model used by the application.

4. Start Ollama.

5. Run the application:
   
   "streamlit run app.py"
